# Ejercicio 4 (opcional) — Reto para ti ✍️

> Lección 01 · refuerzo. Este lo resuelves **tú**: una solución mala (que funcione)
> y una buena.

**Problema:**
1. Guarda una ciudad (`Lima`) y un país (`Perú`).
2. Muestra `Vivo en Lima, Perú`.
3. Luego la ciudad cambia a `Cusco`: muestra `Vivo en Cusco, Perú`.

**Tu turno:**
- Escribe tu versión mala (pero que corra) en [`solucion_mala/main.py`](solucion_mala/main.py).
- Escribe tu versión buena en [`solucion_buena/main.py`](solucion_buena/main.py).

> Pista para la buena: recuerda la **reasignación** de la lección (cambiar el valor de
> una variable en un solo lugar).

**Para compararlas** cuando tengas tus dos versiones (desde esta carpeta):
```bash
git diff --no-index solucion_mala/main.py solucion_buena/main.py
```
